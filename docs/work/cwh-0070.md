## Scope

Select the first skill ever granted automatically, keep the current selection on later grants, and
keep the enable tip for each new grant.

## Criteria

- At most one skill is selected, and selecting another owned skill replaces it.
- The sole selected skill cannot be toggled off.
- Ownership and selection persist across retries and Continue and reset on confirmed Restart.

## Decisions

- Developer grants never select themselves.
- Approval rests on the rulebook's first-gift selection rule as committed in 677b57ac.

## Outcome

The Chibi Abilities rule states first-gift auto-selection with the enable tip. The user reaffirmed
no auto-select on 2026-11-18, and a new item will supersede this one.
