## Scope

Show a waiting update on every arrival at the start screen, including launch, Back to title and
resuming the app on the start screen. A cancel hides it only until the next arrival, and closing a
card is not an arrival.

## Criteria

- The page-session dismissal is replaced by per-arrival dismissal.
- Arrival checks in the background and never activates an ordinary update.

## Decisions

- Achievements, Settings, Restart and nested install cards suppress the offer while they cover the
  start screen.

## Outcome

The Start screen Updates rule describes per-arrival dismissal, and the pinned game-kit update flow
clears dismissal on each arrival.
