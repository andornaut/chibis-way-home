## Scope

Give the source the structure the shared kits use, with unchanged behaviour. One import check
places every module in a named layer, allows imports only downward, counts type-only cycles as
cycles and admits imports from another directory only through its public entry, `data`
excepted. The rule against ambient effects covers the four lowest layers, and a size ratchet
lets file and function sizes only shrink. The simulator, test harness and tools stay in `src/`
as the highest layers, which shipped code never imports. The steps land one at a time: the check,
build code in one directory, the page save as a factory, the type cycles, `rules` split into
bird, boss, stage and zone areas, relocated test-only modules and removed dead exports, and the
oversized functions split while the recorded hashes still pin identical output.

## Criteria

- The check passes with an exception list that only shrinks, ending empty.
- No type-only or value import cycle remains.
- Every directory except `data` is imported only through its entry.
- Each step leaves recorded output unchanged.
