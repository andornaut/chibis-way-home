## Scope

Give the source the structure the shared kits use, with unchanged behaviour. Every module sits
in a named layer, imports point only downward, no runtime import cycle remains, and an import from another directory goes through its public entry, `data` excepted.
The simulator, test harness and tools stay in `src/` as the highest layers, which shipped code
never imports. The steps land one at a time: build code in one directory, the page save as a
factory, `rules` split into bird, boss, stage and zone areas, relocated
test-only modules and removed dead exports, and the oversized functions split while the recorded
hashes still pin identical output. A temporary import check runs during the migration with a table
of known violations that only shrinks; when the table is empty the check is removed and ESLint
guards the layers, together with the rule against ambient effects in the four lowest layers and a
size ratchet that lets file and function sizes only shrink.

## Criteria

- The known-violations table is empty, the temporary check is removed and ESLint guards the
  layers.
- No runtime import cycle remains; type-only imports point down or stay within their band.
- Every directory except `data` is imported only through its entry.
- Each step leaves recorded output unchanged.

## Outcome

Build code sits in `src/build` behind one entry, with the built output unchanged apart from the
source path named in the `_headers` comment. The page save is a factory over explicit storage and
state, which `src/scenes/save.ts` instantiates once under unchanged names and signatures. The
temporary import check runs in lint with its table of known violations.

`src/rules` is four areas, `bird`, `boss`, `stage` and `zone`, each imported from outside only
through its `index.ts`, and the layer table orders them so an area imports only the areas before
it. The timed hazards, collision phases and transients sit in `boss` because they read behaviour
state. `ai`, `dev`, `homePage`, `sim` and `testing` have entries that their importers use. The zone
body step, the behaviour slice decision and the assembly run search are split into named helpers
in their files, with the recorded traces, golden plans and certificates unchanged. The known
violations are one against the layers and 46 past an entry.

`crash`, `loading`, `pwa` and `scenes` have entries that their importers use, the frame turn starts
at the game module's explicit call, and `play.ts` sits in a layer above the `main.ts` it loads.
Every built chunk keeps its modules and the page's chunk load order. The known violations are five
past an entry: `crash` and `loading` reaching into `presentation` and `ui`, and the scenes' page
save in `progress`, whose entries would move modules of the game's chunk into the page's first
chunk.
