## Scope

Give the source the structure the shared kits use, with unchanged behaviour. Every module sits
in a named layer, imports point only downward, no import cycle remains with type-only imports
counted, and an import from another directory goes through its public entry, `data` excepted.
The simulator, test harness and tools stay in `src/` as the highest layers, which shipped code
never imports. The steps land one at a time: build code in one directory, the page save as a
factory, the type cycles, `rules` split into bird, boss, stage and zone areas, relocated
test-only modules and removed dead exports, and the oversized functions split while the recorded
hashes still pin identical output. One import check lands last, on the clean tree, with no
exception list, together with the rule against ambient effects in the four lowest layers and a
size ratchet that lets file and function sizes only shrink.

## Criteria

- The import check passes with no exceptions.
- No type-only or value import cycle remains.
- Every directory except `data` is imported only through its entry.
- Each step leaves recorded output unchanged.
