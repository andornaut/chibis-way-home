## Scope

Give level generation one pure entry point. `planStage` takes a request (seed, map node or recipe
key, chunks to avoid) and explicit context (map, chunk library, recipes) and returns the recipe
key, the plan and its middle chunk ids. A second pure function turns the page address, scene data,
recent chunks and an entropy source into that request. The zone scene, the stage preview and the
simulator catalogue call these instead of resolving nodes and seeds themselves.

## Criteria

- The same seed, target and avoid list give the same level as before, pinned by a golden hash of
  every recipe across a fixed seed set, with and without an avoid list.
- The scene chooses no seed, mode or recipe itself and reads the page address through the request
  function only.
- One node-to-recipe resolution serves play, previews and the simulator.
