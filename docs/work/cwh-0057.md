## Scope

Draw each touch settings row with its live control icon, show Shown or Hidden and On or Off states,
and describe each setting's effect.

## Criteria

- Each touch row notes that hiding changes only the drawing and touch still works.
- Reduced motion shows On or Off with its description.
- Install stays an action, not a state row.

## Decisions

- Descriptions state effects without activation instructions.

## Outcome

The Settings card rule defines the rows; their strings live in `src/data/text.ts`.
