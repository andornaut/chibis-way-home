## Scope

Centre a sole visible action, keep secondary actions left and the primary right, and stack vertical
menus with the primary at the bottom.

## Criteria

- Hidden actions do not count toward a row's visible actions.
- Pause and Menu stack Achievements, Settings, Back to title when present, then Resume or Close.

## Decisions

- Back to title is hidden only on Start.

## Outcome

The Interface Action rows rule and the Pause and Menu card rule state the order.
