## Scope

Make each `src/` folder a component that imports only the components below it, and confine
Phaser to the scenes.

## Criteria

- ESLint enforces the component order.
- Only `src/scenes/` and `src/main.ts` import Phaser or a scene.

## Decisions

- Logic, layout and data stay Phaser-free so they unit-test without a renderer.

## Outcome

Camera, stage and ui (58d6dd33), core (16a236f8), assets and presentation (eda4f847), ui
(f07e6ef1) and progress (085393bd) components.
