## Scope

Adopt the published Game Kit release, whose grouped installs fetch only the device's sound
format group.

## Criteria

- A grouped first install and update fetch one sound format's group, not both.
- Offline play, update reuse and save continuity still work.

## Outcome

The game lists no sounds, so the 0.72 build emits the same four untagged update groups and
no sound format groups, and a grouped install or update downloads every group as before. The
build still emits 35 files; the four archives total 2,373,752 bytes (61 fewer than 0.71) and
the engine and game-art groups keep their digests. The kit pin changed the certified lists'
proofs headers and arena hashes; their entries and the City approach evidence are unchanged.
