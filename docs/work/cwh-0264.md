## Scope

Settings shows Open Cheats beside Back in browser tabs only, checked when it opens and at each
action; it replaces the Dev toggle and the Developer controls panel. The Cheats modal is in the
large width family with Cheats then Tools groups, its body scrolls and Close is the bottom primary button. No cheat selects a power-up.

- Cheats: Invulnerability (contact hazards only), a per-power-up run enable, Load stage, Unlock
  all zones and Unlock all power-ups. Any cheat starts a cheat session in which nothing is saved,
  earned or banked; returning to the start screen ends it, and Continue then loads the pre-cheat
  save.
- Tools, which start no session: Show tips again (clears every seen tip), an FPS counter, off by default, as a device setting in the
  bottom-right corner of the device viewport inside the safe area and drawn above everything
  including letterbox bars, and last, after a confirmation, Reset save (progress, statistics,
  achievements, seen tips and grants; device settings stay).

## Criteria

- Cheats are reachable only from Settings in a browser tab.
- A cheat session writes nothing to the save and earns nothing; Continue after it loads the
  pre-cheat save.
- Reset save asks for confirmation and keeps device settings.
