## Scope

Remove one-off interface code. Game Kit gains the card shell, header and close button, switch and
form row, pager, press-area control groups and text roles that this game builds locally, and the
game adopts each on release. Until then the game makes only local changes that leave every pixel
unchanged: shared text-role and button-reset classes and removal of unused styles. Visible
inconsistencies between cards change only after the user reviews before and after captures.

## Criteria

- No card builds its own shell, header, switch row or pager.
- Spacing comes from the group that holds the controls, with no negative margins.
- Every visible change has a reviewed before and after capture.

## Outcome

Done on branch `agent-cwh-0306-kit-components-20261125` on Game Kit 0.82.0; the user reviewed the before and after captures.

- Every card is built by `createCardFrame` on the kit modal frame: an untitled card is named by its label, and the backdrop covers the whole UI layer as the frame's backdrop rect. Action rows, stacks and the Pause grid are kit action groups; a card's groups, its own-target rows and its footer share the frame's press context, so neighbouring press areas meet midway and never overlap. Settings and Cheats rows are kit form rows and switches, both pagers the kit pager, the Pause/Menu entry and skill buttons kit HUD discs (the skill faces in the kit's disc fill) and the stage faces kit button frames. Colours and type come from the kit theme's slots and text roles, with the game's five roles through the kit's game roles.
- The crash screen and the startup failure and capability cards take the game's text roles and colour slots.
- Achievements shows Previous, the page count, Next and Back in one footer row, six entries a page. Install is centred in the Settings card's right column.
- The game's layout tree, its pass-through wrapper nodes, the padding-as-press-area selectors and their negative margins are removed. Start, Map, Opening, conversation, room and stage summary rows are placed by kit groups or CSS.
- Tests that pinned source text or class names are replaced by checks of roles, names, focus order, state and geometry from the kit's pure functions.
- Measured against local main, without the certified lists and the lock: non-test files 2,608 lines added and 2,734 removed in 81 files (stylesheets 339 added and 846 removed); tests 2,477 added and 1,331 removed in 49 files.
- The stage summary spaces its rows by their ink in the loaded font, which the cutscene measures and passes in, so every zone's summary sits as before.
