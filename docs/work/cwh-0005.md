## Scope

Offer Install on the home page and in Settings, start the installed app on the game in full
screen and landscape, and catch back navigation.

## Criteria

- Install shows in every browser until the game is installed, with the browser's steps where it
  has no install prompt.
- Back is caught with a CloseWatcher where the browser has one, and otherwise a guard history
  entry.

## Decisions

- The install flow and back handling come from game-kit's PWA modules.

## Outcome

Home page Install (e9365d1b), installed app start (072fc065), back handling (99988700), and
Install in every browser until installed (85ae8308).
