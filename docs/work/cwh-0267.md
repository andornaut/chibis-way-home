## Scope

Penthouse opens on a screen that looks distinct from the shared apartment floor start: tall
skyline windows and a lighter, upscale palette, built from existing apartment primitives and a new
wall backdrop. The opening keeps the same size, seams and safe lower spawn, so routes and recipes
do not change.

## Criteria

- The Penthouse opening uses its own wall backdrop; the other floors are unchanged.
- Routes, recipes and the spawn are unchanged.
- The Penthouse stage preview is recaptured after landing.

## Decisions

- The opening uses a new 96x144 `apartment-wall-penthouse` backdrop, one tall wood-framed skyline window per repeat between raised panels, so each repeat reads as a separate window.
- Its paint stays on the Apartment near rank: pale plaster and a muted blue sky keep their source residuals, and the trim, panels and towers use the named near wood, light, shade and blue tokens, so the wall keeps the same depth contrast as the other apartment walls.

## Outcome

- Art: `apartment-wall-penthouse` is drawn and registered in the manifest; the other apartment walls are unchanged. The Penthouse stage preview was recaptured at the start camera (c9f3a7ab).
- Tech: Penthouse opens on `apartment-penthouse-start` (73f5c3ec), registered in the route, walk and opening tests like the shared floor start; one certify run refreshed only the certified input hashes (c595976c), every listed entry unchanged.
