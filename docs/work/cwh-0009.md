## Scope

Give every modal card the shared modal input gate and a palette-remapped backdrop.

## Criteria

- Only the top modal receives input.
- Each frozen backdrop is dimmed once.

## Decisions

- The input gate and dimming come from game-kit; the game supplies the palette's one-step darker
  map.

## Outcome

game-kit modal input and backdrop primitives (481e9733), canonical dimming and isolation for
every modal (667e8376), and dimming applied once per backdrop (7a4db29c).
