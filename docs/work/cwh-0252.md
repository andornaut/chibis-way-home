## Scope

Tapping the selected skill deselects it, leaving none active. Tapping another skill switches to
it.

## Criteria

- A tap on the selected skill leaves no skill selected.
- A tap on another eligible skill selects it.

## Decisions

- This replaces the rule that a tap never turns the only selected skill off.

## Outcome

Implemented in 49b009d5: a HUD tap on the selected skill turns it off, and a tap on another
eligible skill switches to it.
