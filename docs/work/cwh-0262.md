## Scope

Pin art-kit 0.31.0 and declare each art build set's outputs, with hand-kept files listed as static,
so the art build check fails on any unclaimed file under its check paths.

## Criteria

- Every build set declares its outputs, and the check runs with outputs enabled.
- A leftover file under a check path fails the art build check.

## Decisions

- Tech pins art-kit 0.31.0; Art declares the outputs.
- Each set's outputs are the exact files its build writes, taken from its writer, with sprite, tileset and backdrop keys expanded to their served files. A file two sets write, such as the manifest, the contact metadata, the street tileset, the apartment doors and the backdrops `backgroundTones` repaints, is listed under each writer.
- Static entries are the art documentation, `art/fonts/` and `art/tools/`. The stage previews are static through the committed manifest's hand-registered image entries, the same rule the manifest reset keeps.

## Outcome

Every build set declares its outputs and the art build check runs with outputs enabled, so a file under the check paths that no set or static entry claims fails it. The declaration changes no generated file, and no unclaimed leftover was found.
