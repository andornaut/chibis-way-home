## Scope

Start shows the Menu control and an Exit button only where exiting works in the current runtime, detected at runtime. Pause and Menu are one modal: Menu with a Close bottom button on Start, Pause with a Resume bottom button in game, the bottom button primary. In game, Back to title sits directly above the bottom button. Every other button is ordered alphabetically by label.

## Criteria

- Exit shows only where exiting works, detected at runtime.
- The bottom button is Close on Start and Resume in game, in the primary style.
- In game, Back to title sits directly above the bottom button; other buttons are alphabetical.

## Decisions

- Runtime Exit detection follows Archie's existing Android installed-app detection.

## Outcome

Exit shows and closes only in a closable app window, and the shared card follows the policy order (commit "Show Exit only where it closes the app").
