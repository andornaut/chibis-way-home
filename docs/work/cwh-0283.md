## Scope

Pin Game Kit 0.64.0 after verification that Chibi uses the supported interfaces.

## Criteria

- The source pin, lock and installed package match the immutable release.
- Executable imports resolve to public interfaces and use no retired aliases.
- Native certification inputs and output evidence remain equivalent. Update only provenance
  that binds the package pin.
- Existing game behaviour, saves and pack configuration stay the same.

## Decisions

Reuse the checked public interfaces and the existing certification tooling.

## Outcome

Pinned the immutable 0.64.0 release. All 97 executable import paths remain public, and the
18 native package modules and declarations match the prior pin byte for byte. Updated
certificate hashes that bind the package release and kept the recorded evidence.
