## Scope

Follow the shared [procedural systems policy](https://github.com/andornaut/game-coordinator/blob/main/docs/game-policies.md#procedural-systems).
Replace recorded per-seed plan hashes and per-trace behaviour, ability and effect hashes with
contract and property tests plus one bounded acceptance batch. The plan golden set stays only as
a marked temporary scaffold while identical-output refactors are in flight. The remaining gaps to
the policy's entry point, stream and result rules are listed and closed here or in linked items.

## Criteria

- No recorded hash fixture is a lasting pin for level generation or boss behaviour.
- Property tests state each rule the hashes protected, and the seven-arena batch is the
  acceptance check for boss behaviour.
- The plan golden set carries a cleanup marker with its removal condition, then is removed.

## Outcome

Every recorded plan and behaviour hash is retired; property tests state the rules they protected,
and `make acceptance` proves the seven admitted arenas once (about 70 seconds, outside
`make test`). [Pins and acceptance](../../src/README.md#pins-and-acceptance) describes both.

| Recorded hash                                        | Rules it protected                                                       | Replacing test                                                              |
| ---------------------------------------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| Plan golden set, 22 recipes by seeds 0 to 15         | Determinism, seams, width, band, `maxPerZone`, repeats, loops, avoidance | `stagePlanProperties.test.ts`                                               |
| Walk traces, every chunk's required walk             | Each chunk's required targets reached                                    | `chunkWalk*.test.ts`                                                        |
| Encounter traces, admitted arenas, crossing and lift | Boss fairness in the encounter scenarios                                 | `bossProperties.test.ts`, `bossDodges.test.ts`, simulator equivalence       |
| Stage traces, five stage runs                        | City cold encounter; Pebble survives the loading-yards run               | `cityEncounter.test.ts`, `flyerSurvival.test.ts`                            |
| Ability traces, every boss graph state               | Pebble's flights, overhead pursuit, landing, committed attack and spawn  | `pebbleAbilities.test.ts`                                                   |
| Effect traces, four bosses' entry effects            | Growl pulses, parcel and dropping spawns reach the zone                  | `behaviourEffects.test.ts`                                                  |
| Simulator's recorded encounter hashes                | The simulator reproduces the zone step                                   | `bossSimulator.test.ts` equivalence and replay                              |
| Sample arena hashes in `evade.test.ts`               | Sample arena proofs unchanged                                            | Each sample passes its proof, hashed over arena, chunk, traces and game-kit |
| Archie's movement map hash snapshot                  | His pursuit map build unchanged                                          | Identical builds hash identically; map content in `movementMaps.test.ts`    |
| Certified lists' `inputs.proofs`, fixture part       | Recertify when trace fixtures change                                     | Proofs hash covers game-kit and version; `verify` reproves recorded traces  |
| City approach trace against the stage trace fixture  | The approach requalified on any behaviour change                         | `cityEncounter.test.ts`; `verify` checks the trace's format                 |

- The plan golden set carried its `CLEANUP` marker and is removed: no identical-output refactor of
  stage planning is in flight.
- New properties: a boss's body stays lethal through its attack cooldown, and a save in the current
  shape that the previous version wrote resets.
- The certified lists keep their entries, arena hashes and City approach evidence; only
  `inputs.proofs` changed, from `31dd738bfda62cc1` to `d3e8a36d43b448d1`.
- Not stated as tests: Trixi's trap spawn at zone level (she rushes a still Chibi beside her
  first), and a 600-tick continuous ordinary route for every pool chunk and every connector (the
  older connectors have walk proofs only).
