## Scope

Reduce shipped art files and bytes by packing the Start background into a shared atlas.

## Criteria

- Preserve source artwork, frame pixels, the device texture limit and offline loading.
- Keep stage previews on their own sheet and compare matched production builds.

## Decisions

Add a 1792 px packing width and share an existing atlas family with the static Start background.

## Outcome

Matched builds reduced the precache from 41 to 40 files and by 1,766 raw bytes. The full
production output dropped from 53 to 52 files and by 1,935 raw bytes. The preview sheet stayed
byte-identical. All atlas pixels and frames were verified, and the browser reached Start without
requesting a standalone background. Editing that background now refreshes its shared atlas page.
