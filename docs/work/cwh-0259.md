## Scope

The deployed build carries only what the player uses: no art gallery or tuning pages, no
per-file art copies the game loads from atlases, no unreferenced icon or favicon copies, and each
data file shipped once.

## Criteria

- `dist/` holds no gallery, tuning or per-file art copies and no unreferenced images.
- The palette and art manifest ship once.
- The game, offline install and precache are unchanged for the player.

## Decisions

- Developer pages stay available in the development server.
