## Scope

Show Pause only over active pausable content and a three-line Menu elsewhere, from one entry in the
same position, with Settings nested and Achievements in the non-game Menu.

## Criteria

- Start and the map always use Menu, with Menu and Close.
- Achievements opens from Menu, not from gameplay Pause or a start-screen icon.
- Settings and Achievements return to the same card and mode; Achievements has a Back label.

## Decisions

- Titles stay centred near the top, unobscured by controls.

## Outcome

The Settings section's Open and Pause and Menu card rules define the entry; strings live in
`src/data/text.ts`.
