## Scope

Adopt the compatible Game Kit focus-wake patch and verify update discovery in an installed
Chibi app.

## Criteria

- Use the verified public package and lock. Preserve game data, native route evidence and
  certificates apart from provenance that binds the package version.
- A real installed-window focus event enters the existing guarded update check.
- Accepting a staged update requires an explicit action, navigates once and preserves saved
  progress and statistics.

## Decisions

Use the existing discovery scheduler and its cooldown. Keep the active build until the user
accepts the update.

## Outcome

Game Kit 0.64.1 shipped in `1e078df5` after the scheduled gate and CI passed. One
explicit Update now action in installed desktop Chrome navigated once and preserved the
save and statistics bytes.

On the new build, native window focus caused a successful update pointer request after
the existing cooldown. The app stayed on the same document and active build. This
verified focus with unchanged visibility on desktop Chrome. Phone resume and activation
of a later release from the fixed client remain unverified.
