## Scope

Offer a newer build once it is ready, and update automatically when the save was written by a
newer version.

## Criteria

- The offer is a compact dismissible modal; a dismissed offer stays hidden for the page session.
- A save from a newer version blocks save writes and tries a newer complete build before Start
  opens.

## Decisions

- A newer save never downgrades: the running page updates instead of writing.

## Outcome

Update offer (0d98ec89) as a compact modal (40093165); automatic update for a newer save
(ced5ea42); dismissal kept for the page session (c95172d9).
