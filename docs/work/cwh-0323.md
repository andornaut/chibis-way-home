## Scope

Review performance across startup, gameplay, stage assembly and verification. Measure and
implement the highest-impact findings that can preserve gameplay and supported workflows.

## Criteria

- Use repeatable workloads and record comparable baseline and candidate measurements.
- Preserve existing gameplay, deterministic outcomes, asset fidelity and verification criteria.
- Run focused regression checks and the existing release checks for the integrated changes.

## Outcome

Hazard occupancy reuses immutable graph metadata across snapshots, calculates fixed padding
once per snapshot and checks only actual zero-time graph edges. In the isolated three-stage
engine workload, median time per 2,880 steps fell from 2,701 ms to 2,087 ms. Terminal state
hashes matched, and native Penthouse proof records were byte-identical. This measures Node
engine-step time. Browser rendering, networking and phone performance remain unmeasured.
