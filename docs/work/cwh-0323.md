## Scope

Review performance across startup, gameplay, stage assembly and verification. Measure and
implement the highest-impact findings that can preserve gameplay and supported workflows.

## Criteria

- Use repeatable workloads and record comparable baseline and candidate measurements.
- Preserve existing gameplay, deterministic outcomes, asset fidelity and verification criteria.
- Run focused regression checks and the existing release checks for the integrated changes.
