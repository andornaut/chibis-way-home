## Scope

Use Chibi's keyboard-focus cue in the playable game and a visible system-colour cue in forced
colours. Keep the same focus, tab order, activation and restoration behaviour. Keep the artwork
for normal, pressed, selected and disabled states.

## Criteria

- Keyboard focus is visually identifiable on game controls, including startup and recovery.
- Pointer use does not add a generic browser outline. Keyboard activation and modal focus
  restoration work as before.
- The focused face remains visible in forced colours.

## Outcome

Chibi uses fill and ink for keyboard focus on game buttons, with system colours in forced
colours. Game Kit supplies the corresponding startup Retry and crash Reload presentation.

Isolated Chromium verified the Menu, skill controls, and recovery actions in normal and forced
colours. A single keyboard Retry recovered to the worker-controlled Start screen. Native details
disclosure retains its own cue.
