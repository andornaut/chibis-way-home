## Scope

Reduce redundant cases and repeated setup in Chibi's test suite. Prefer data-driven cases
for behaviours with meaningful input variations.

## Criteria

- Record before and after executed case counts and comparable runtimes.
- Identify the surviving check for each removed case.
- Preserve distinct edge cases, production contracts and required verification.
