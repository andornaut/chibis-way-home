## Scope

Label the existing primary footer in Cheats Back because it returns to the Menu or Pause
that opened Cheats.

## Criteria

- The sole footer button says Back. The entry action still says Cheats.
- Back and the top-right X return one modal layer and restore focus to the invoking control.
- The placement, size, return action and held gameplay state stay the same.

## Decisions

The top-right X keeps its accessible Close name.

## Outcome

The sole primary footer now uses the existing Back label. The X and footer share their
original return callback and restore focus to the Cheats entry. Focused modal tests cover
the label, return and preserved Reset save guard.
