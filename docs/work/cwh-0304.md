## Scope

Adopt the published Game Kit release. Grouped builds ship gzip group archives, which the site
deploys and serves, and grouped installs decode them in the browser.

## Criteria

- The deployed site serves the compressed group files, and a grouped first install and update
  fetch them.
- A browser without the needed decoding support shows the shared startup error.
- Offline play, update reuse from 0.72 and save continuity still work.
