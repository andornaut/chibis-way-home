## Scope

Supply the accessible-name and live-region strings for each remaining screen as it moves to page
elements, extend the Accessible rule's lists, and remove its CLEANUP sentence once every screen has
moved. The Accessible rule's CLEANUP sentence (411ddb18) and the HTML UI layer
([cwh-0016](cwh-0016.md)) set this scope.

## Criteria

- Every moved screen's controls have names from the player strings.
- The Accessible rule lists every screen, and its CLEANUP sentence is gone.
