## Scope

Use Next when advancing opening captions and standard story dialogue. Keep the gift-room exit
labelled Continue and ordinary room exits labelled Leave. Keep existing action identities,
explicit choices, Skip and saved-game Continue.

## Outcome

The gift-room exit reads its own text field. Opening and story dialogue use the shared
Next label, with the same input and navigation behaviour.
