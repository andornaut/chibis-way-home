## Scope

Use published Game Kit construction, state presentation and discrete input for standard text
and icon buttons across menus, modals, the HUD and startup. Chibi retains skins, labels,
placement and callbacks. Continuous gestures and native editing keep their existing semantics.

## Criteria

- The construction guard rejects unsupported local standard button creation. Compound controls
  retain their content and availability semantics.
- Pointer, keyboard, touch and hold actions preserve their existing results and state transitions.
- Keyboard and forced-colours cues, modal destinations and focus restoration remain correct.

## Outcome

Standard game actions use the Game Kit button factory and shared input binding. Compound controls
retain their existing semantics. The construction check also covers Stage Select's page buttons.

In isolated Chromium, an unavailable pager skipped keyboard focus and gave its existing feedback to
a pointer press without changing the page. The opposite pager moved between pages and updated the
focusable actions. Startup Retry used the shared content width and kept focus through resize.
