## Scope

Reuse a hazard envelope within a behaviour snapshot when the queried horizon admits
the same transition arrivals. Preserve the exact cached results and unknown cases.

## Criteria

- Compare repeated baseline and candidate elapsed work on the same inputs.
- Preserve terminal and arena evidence and check both sides of a horizon boundary.
- Compare live play using the same browser, renderer and moving-camera workload.

## Verification

The matched three-stage engine benchmark fell from 1,957 ms to 667 ms median.
Terminal hashes across all runs matched, and the Penthouse proof was byte-identical.
One matched moving Ravine replay pair on Chromium with desktop SwiftShader software
rendering measured a 50.0 to 33.4 ms p99 frame interval and an unchanged 33.4 ms p95.
This single pair covers the measured desktop workload. Phone performance remains unmeasured.
The candidate deployed on 2026-11-27 from commit `3de7bc1f` after the full gate and CI passed.
