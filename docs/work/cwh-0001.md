## Scope

Serve the game at `/play/` beside a home page at `/` from Cloudflare Workers static assets, and
write a Content-Security-Policy for each page.

## Criteria

- Each page is an HTML input in `pages/` at its URL's path.
- The build writes `dist/_headers` with a policy per page whose inline blocks are hashed.
- No Worker script runs.

## Decisions

- Static assets only: the game needs no server code.

## Outcome

The game at `/play/` and the home page at `/` (25be66ed); `dist/_headers` with a hashed
per-page policy (cea0331c).
