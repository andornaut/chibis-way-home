## Scope

Move the existing FPS counter toggle from Cheats to Settings. Display the readout at the
top-right of the device viewport.

## Criteria

- Settings shows the FPS counter switch. It is off by default and preserves the existing
  device preference in browser and installed play.
- The enabled readout stays inside the safe area and above the game and letterbox bars.
- Toggling the counter leaves the game save and cheat session intact. Show tips again remains
  in Cheats.

## Decisions

Use the existing setting and counter with their current label.
