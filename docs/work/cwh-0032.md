## Scope

Open the game on a start screen with Start, Continue, Restart and Exit, give play a pause card with
Settings and Back to title, and offer waiting updates in a compact start-screen modal.

## Criteria

- Back to title always goes to the start screen.
- Restart shows only after an actual stage entry and asks first on a card.
- Exit shows only where it works: browser tabs and closable installed apps.
- A waiting update is offered only on the start screen, with Cancel and Update now.

## Decisions

- The home page is the website's page at `/`; the start screen is the game's first screen.
- Clearing the final stage celebrates with Continue and Restart.

## Outcome

The Start screen and Settings sections define the screens; their strings live in `src/data/text.ts`.
