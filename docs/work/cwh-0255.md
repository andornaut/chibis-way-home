## Scope

Give the opening story root a role and name, the start screen root a name and its logo a text alternative, and take the play page's accessible game name from the text data instead of hard-coded markup.

## Criteria

- Each named element reads its name from the text data.
- The play page carries no hard-coded player string.

## Decisions

- Gameplay supplies the strings and extends the Accessible rule to these screens.

## Outcome

The opening and start regions, the logo and the play page take their names from `TEXT` (commit "Name the opening and start screens and the game page from the text data").
