## Scope

Install game-kit and art-kit from their version-pinned GitHub release tarballs instead of a
vendored copy, and resolve them through package exports.

## Criteria

- `package.json` pins each release and `package-lock.json` records its checksum.
- Runtime imports use `@andornaut/game-kit/<path>` without source aliases.

## Decisions

- Games consume only released, pinned kit versions.

## Outcome

Published game-kit releases (bdcd6690, fe0ba3cc), resolved through package exports (84db5ba0);
art-kit's published APIs (43ada0de). Current pins: game-kit 0.56.1 (ce3bfe10) and art-kit 0.29.0
(2a86b074).
