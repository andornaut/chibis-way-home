## Scope

Add a Back button centred at the bottom of the Settings modal.

## Criteria

- Back stays in the footer when the settings body scrolls.
- Back and the header X share dismissal and restore the invoking Menu or Pause state and focus.
- The top dialog owns input. Install steps keeps its existing dismissal and returns to Settings.

## Decisions

Use the standard modal action and the current guarded return path.

## Outcome

Settings has a centred Back button below its scroll body. Real touch checks verified that
it stays fixed while the body scrolls, returns to Menu or Pause with focus restored, and
acts once when held. Install steps keeps the underlying Back button inactive.
