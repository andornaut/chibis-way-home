## Scope

Adopt the published Game Kit release and use prebuilt archives for gameplay first install and updates.

## Criteria

- Keep the bootstrap and intentional direct resources available and account for hosted files and bytes.
- Show the shared startup error if required browser capabilities are unavailable.
- Verify first install, grouped update reuse, offline play and save continuity.

## Decisions

- D1 (user, 2026-11-24; answers q-chibi-grouped-no-storage): We should just display an error message in that case.

## Outcome

The build emits 35 files, down from 52. It hosts four archives totalling 2,373,813 bytes
and 31 direct files totalling 374,887 bytes. The direct startup shell accounts for 317,905
bytes also present in the offline archives. Deferred game code, packed art and game metadata
have no loose copies. Total raw output grows by 324,078 bytes.

The shared startup error appears before loading the game or reading the save when either
required browser feature is missing. A fresh Chromium session installed and reopened offline.
An existing 0.69 save survived acceptance of the archive build and offline restart.
