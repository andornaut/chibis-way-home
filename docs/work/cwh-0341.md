## Scope

Pass the Game Kit build identity into Chibi's precache producer.

## Criteria

- The production build pointer and its manifest identify the same full SHA as
  the clean source checkout.
- A dirty or unverified checkout keeps the kit's existing `dev` identity.
- Verify the production pointer and manifest after the normal delivery.
