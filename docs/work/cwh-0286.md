## Scope

Audit the top-right X in each closeable modal and fix any mismatch with its corresponding
Back, Close, Cancel or Resume action.

## Criteria

- A real browser tap, or a hold where supported, calls the existing action once.
- Dismissal affects the top dialog and restores the immediate parent, pause state and
  invoking focus where available. Covered controls stay inactive.
- Mandatory choices with no valid cancellation remain nondismissible.
- Verification lists the audited callers, the exact source and real pointer results.

## Decisions

Use each dialog's existing authorized action and the shared input binding.

## Outcome

The shared close actions preserve the immediate parent and cancel during an inactive
modal scope. Settings and Install steps restore the invoking button after touch
dismissal. Stage select restores Map's previously focused action when Map restarts.
Cheats and its reset confirmation respect the busy guard.

Chromium pointer checks covered Menu, Pause, Achievements, Settings, Install steps,
Cheats, Stage select, Restart, Reset save, skill details and the Update offer.
The deployed Update offer closed on X, kept the existing game document and save,
and left the available update staged for later. The exact deployed source was
`c65a28b6fd24dc45f3451185fa166a1f35fdb8a6`.

Black-bar clicks behind Settings dismiss one layer, restore the invoking focus
and keep Pause active. Behind a required Conversation, they leave the view open
and trigger no underlying action. Chromium checked wide, tall and turned frames.
