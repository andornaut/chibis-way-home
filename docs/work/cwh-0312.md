## Scope

Adopt the published Art Kit release, whose validation errors share one wording and whose
generated output is unchanged.

## Criteria

- A plain build of every art generator leaves the committed outputs unchanged.
- Tests that match Art Kit error text follow the new wording.

## Outcome

The pinned tarball matches the release SHA-256, and the lock's integrity equals its SRI. No test,
generator or build adapter matches Art Kit message text, so none changed: the art and atlas tests
match only local messages or mock the kit. The local `Point` and `Rect` tuple types differ from
the kit's object types, and `fonts.ts` declares no glyph atlas type, so no type import changed.
`build.ts --check` and a plain build of every generator leave all 375 files under the check paths
byte-identical. The certified lists verify unchanged.
