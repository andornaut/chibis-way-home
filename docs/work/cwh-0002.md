## Scope

Show game-kit's crash screen in the game's palette on an uncaught error and pause the game.

## Criteria

- The crash screen installs before the loading strip, Phaser or any game module runs.
- It writes nothing to the save.
- Its details show the build label.

## Decisions

- The loading entry installs the crash screen first, so an error during startup still reaches it.

## Outcome

The kit's crash screen pauses the game (6563ee03), installs from the loading entry with one
shared build label (c3c8e423) and uses readable Liberation fonts (7790462f).
