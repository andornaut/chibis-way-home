## Scope

Adopt the published Game Kit release, including its shared HUD disc rims and form-row sizing.
Use the shared control paths for refused actions and sliders where they apply.

## Criteria

- Preserve control placement, press targets, focus and input behaviour.
- Compare the affected screens before and after at 844×390 and 720×360.
- Refresh proof provenance and pass the normal gate and arena acceptance.

## Decisions

- D1 (user, 2026-11-26; answers q-cwh-0316-shared-disc-rendering): Use shared Game Kit rendering (Recommended)

## Outcome

Chibi uses Game Kit for the face, rim and ring of the Menu, Pause and Exit discs. Their SVGs
supply the glyphs. The control positions and hit boxes matched the previous build in the
844×390 and 720×360 comparisons. Chibi uses the shared form-row API where applicable, with
no slider in the current interface.

The certified layouts and arenas retain their existing entries and use current Game Kit
proof provenance.
