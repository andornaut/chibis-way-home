## Scope

Keep Reset save in the Cheats tools and make its availability follow valid stored game data.

## Criteria

- Show the disabled action on a fresh profile, for default-only storage, and after reset.
- Enable the action for valid stored game data. Disabled actions cannot open confirmation.
- Cancel and the close X preserve the save. Confirm clears game data and keeps device preferences.

## Decisions

Use the existing confirmation and disabled button presentation.
