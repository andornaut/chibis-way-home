## Scope

Define runs and attempts, record active time, and show an image-backed statistics interstitial on
every clear, retry and zone end.

## Criteria

- Attempts count the first try, each Try again and each re-entry after leaving uncleared.
- Best time keeps the fastest successful attempt in a separate stats save.
- Only confirmed Restart clears the totals.

## Decisions

- Time in a stage's gift rooms counts as active play.
- Each statistics entry shows one static statement from the zone's antagonist.

## Outcome

The Stage statistics and interstitials section defines the fields and lifecycle.
