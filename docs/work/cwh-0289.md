## Scope

Swap the two actions in the in-game Pause card.

## Criteria

- Pause displays Achievements, Settings, Cheats, Back to title and Resume in reading
  and keyboard order.
- Menu retains its current order and Resume remains the primary action in Pause.

## Decisions

The corrected pair is Cheats and Settings.

## Outcome

Pause places Settings before Cheats, and keyboard focus follows that same order.
The Start and Map Menu order remains unchanged. The shared card still returns from
Cheats to its invoking action.
