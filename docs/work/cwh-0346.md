## Scope

Correct the shared action sizing that clips the Start button label when the
game frame turns on a touch device in portrait.

## Criteria

- The Start face contains its label in the turned and unturned game at
  fractional scale.
- Keep the existing button order, layout, artwork and activation rules.
- Use the published Game Kit measurement fix through the existing caller.

## Outcome

Game Kit 0.94.2 keeps the Start face at 69 × 48 base pixels when the game
turns. A live Chromium touch check at fractional scale confirmed that the
whole label fits in portrait and landscape, and Start still accepts a tap.
Physical Firefox Android was not retested.

Released in `9eb962a1`.
