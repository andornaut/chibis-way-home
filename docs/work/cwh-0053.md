## Scope

Add a Reduced motion setting that starts from the device preference, and show Install in every
browser until the game is installed, with each browser's install steps.

## Criteria

- Reduced motion removes screen shake, flashing and feedback motion, including the hazard cue and
  boss removal puff.
- Install shows the browser's prompt where it has one, and otherwise a card with that browser's
  steps.

## Decisions

- Install steps text matches the other games.

## Outcome

The Settings card rule lists both rows; install steps live in `TEXT.settings.installSteps`.
