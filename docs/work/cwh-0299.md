## Scope

Remove the cheat session. Cheats, cheated runs and runs started from a run link save, bank and
earn progress, unlocks, achievements and statistics like normal play. Cheats chosen on Start
apply to the next Play or Continue. Restart returns to a new save.

## Criteria

- No cheat holds, discards or restores the save; returning to Start keeps cheated progress.
- Cheated play earns, announces and stores achievements and statistics as usual.
- The Cheats card no longer says that cheats stop saving.
- Restart still returns to a new save.
