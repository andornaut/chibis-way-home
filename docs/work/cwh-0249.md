## Scope

Align the Settings rows in `art/style-guide.md` and `art/controls.md` with source 1aa00683.

## Criteria

- Each switch row's note is that switch's description text in dslate, Reduced motion included;
  Install has no note.
- Rows are at least 48px high and grow for wrapped notes.
- Each switch row shows a right-aligned, aria-hidden state word 8px before its switch: Shown or
  Hidden for the touch rows, On or Off for Reduced motion.

## Decisions

- The guide cites `settings.descriptions` rather than copying the note strings, so the player strings stay in data.
- The keyboard focus bullet drops its fixed 48px row height too, since a wrapped note makes a switch row taller.

## Outcome

- `art/style-guide.md` and `art/controls.md` describe each switch row's own description note, rows at least 48px that grow for wrapped notes, and the aria-hidden state word 8px before the switch.
