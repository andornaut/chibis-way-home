## Scope

A build-time projection keeps only the fields the runtime reads from `src/data/certified/*.json`,
while tools and tests keep the full files. The palette and art manifest ship once instead of as
both a JS chunk and a JSON file.

## Criteria

- The runtime layout import carries no verification-only hashes; tools and tests read the full
  files.
- The palette and art manifest each ship once.
- Before and after raw and gzip sizes are recorded.

## Decisions

- No trimmed Phaser build, compact atlas encoding or console stripping; the build keeps Oxc.
