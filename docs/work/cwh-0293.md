## Scope

Fit Cheats on one screen in a narrower, single-column modal. Use the normal map
for stage selection.

## Criteria

- Stack Unlock all power-ups and Unlock all zones with the shared button gap.
  The button labels describe the actions.
- Remove the zone picker, stage picker, Load stage, individual power-up switches,
  Reset save and Show tips again.
- Show Invincibility as the sole switch, with its visible state below the switch.
- Preserve cheat-session save protection, Start's Restart confirmation, ordinary
  first-time tips and modal navigation.

## Decisions

Keep the Start screen's Restart. Remove the Show tips again button from every game.

## Outcome

The Medium Cheats card fits two stacked unlock actions, the contact-only Invincibility
switch, session feedback and centred Back. Unlocked zones are available from the map.
Start's Restart and ordinary first-time tips retain their existing behaviour.
