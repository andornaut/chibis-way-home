## Scope

Request an update check through the shared scheduler when Chibi accepts a start
of play or returns to Start.

## Criteria

- Accepted Start, Continue, restart confirmation and stage selection request a check.
- Returning to Start after Reset requests a check only when leaving another view.
- Refused, repeated or cancelled actions do not request another check.
- These actions stay in the same document and leave update activation to Game Kit.

## Decisions

Reuse the shared scheduler. A complete staged build may activate on the next cold
launch. An update that finishes in the open game still uses the confirmation modal.

## Outcome

Accepted Start, Continue, restart confirmation and stage selection now use Game
Kit's shared check. Reset uses the same return-to-Start path when leaving another
view. The focused checks on the installed 0.65.0 package passed. The full
installed-app updater qualification belongs to the shared policy work.
