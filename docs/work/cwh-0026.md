## Scope

Split the `Test` workflow so a first job detects changed paths, lint always runs, and the heavier
jobs are skipped by condition when only `docs/` changed.

## Criteria

- A docs-only change runs only lint and the AI attributions check.
- Any other change runs every job.
- Required checks accept a skipped job.

## Decisions

- The game never serves or packages `docs/`.

## Outcome

A first `Changes` job classifies changed paths; `Test` runs unless every changed path is under
`docs/`, so a failed or missing classification still runs it, and `Lint` and AI attributions always
run. `Changes` is a required check (a5fa77a9).
