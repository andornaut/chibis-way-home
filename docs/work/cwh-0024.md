## Scope

Give every modal card a static width family: large 688, medium 500 or small 400, narrowed to the
view less a 16 px screen margin on each side.

## Criteria

- Large: Stage select, Achievements, Settings, Skill details, room gift and Death.
- Medium: Pause and Menu, and Install steps.
- Small: Update, Restart, dialogue choice, connect status and the celebration placeholder.

## Decisions

- game-kit publishes no families, so they are game geometry in `src/data/layout.ts`.

## Outcome

Width families with the screen margin (782a52c5), Settings in the large family (dd4097b7) and the
static assignment in the source guide (ee495f22).
