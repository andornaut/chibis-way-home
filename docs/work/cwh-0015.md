## Scope

delivery-kit gates local `main` HEAD in an isolated container, pushes that exact commit, waits for
its CI and deploys the gated build with Wrangler.

## Criteria

- Departures run hourly at :20 America/Toronto.
- Pushes and deployments are not made by hand.
- Failures are fixed forward.

## Decisions

- The gate image is an immutable local image ID pinned in `delivery-kit.json`.

## Outcome

delivery-kit configured and pinned (2e4e1f5d), departures moved to :20 (f924972c), delivery-kit
4 with explicit gate memory (8e7db3c1) and the public 4.6.0 pin (d3faf2b2).
