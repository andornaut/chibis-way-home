## Scope

Use the same Settings Install presentation as Archie and Ada.

## Criteria

- Show one accessible Install action with the decorative down-arrow-to-tray
  icon and one visible label.
- Keep the action in its existing place and show it only when installation is offered.
- Preserve tap, hold, keyboard and focus behaviour. Activation opens the native
  prompt or the existing browser-specific steps.
- Fit the Settings card without scrolling.
