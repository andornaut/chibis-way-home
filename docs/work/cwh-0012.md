## Scope

Run lint, test and build inside a check container built from a digest-pinned image, and run CI
through the same Make targets.

## Criteria

- Containers run as UID 19001 with read-only host mounts, capped at four CPUs and 8 GiB.
- A container starts only while the one-minute load is below 20.
- The npm check scripts call the same recipes in the current environment.

## Decisions

- Admission depends only on the one-minute load.

## Outcome

Non-root, read-only containers (ee0afe24), admission on one-minute load (7bf8bdef), CI through
Make (a7b1b047), and Node 24.22.2 with a digest-pinned image and `tests/container/check`
(8e1e3a05, a4059f1b).
