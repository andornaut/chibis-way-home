## Scope

Each timed hazard keeps one transition budget for a whole tick, shared by every object that
queries it that tick, so earlier far queries can make a later near query answer "unknown". Each
query gets its own budget, so an answer depends only on what was asked.

The support sampler handed to the encounter step has no order dependence: evaluating it eagerly
changes no output and only costs more, contrary to the cwh-0308 outcome. It stays lazy for cost.

## Criteria

- A timed hazard query answers the same regardless of how many queries ran before it in a tick.
- Recorded behaviour changes only where the shared budget ran out, measured before the change.
