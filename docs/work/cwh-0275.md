## Scope

Move the existing Cheats entry from Settings to the shared Menu and Pause. Expose it in browser
tabs and installed apps. Keep the existing Chibi control order and layout, save rules and tools.

## Criteria

- Menu and Pause each expose one Cheats entry. Settings has none.
- Closing Cheats returns one layer to the invoking control. Covered actions stay inactive.
- Cheat effects remain session-only, and Reset save still requires confirmation.
- Menu and Pause retain their standard action sizing and a visible bottom primary action.

## Decisions

The shared Cheats entry and display-mode policy replace the entry and availability rules of
cwh-0264. Its action and save rules remain in use.

- D1 (user, 2026-11-22; answers q-cwh-0275-five-button-fit): Keep 16 px margins and arrange the actions in two columns

## Outcome

The shared Menu and Pause expose one Cheats entry. Settings no longer owns a Cheats entry.
The five-action card fits two columns and a centred bottom primary at standard sizes and
margins, without scrolling. The Start menu retains its four-action stack.

Isolated Chromium verified the browser tab and a supplied standalone display mode. Close and
X returned focus to Cheats, and Reset Cancel returned to Reset save without changing the save.
