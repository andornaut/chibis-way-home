# Movement and skills

Ordinary movement includes variable-height jumps, flutter, coyote time and jump buffering. The
[Grid](../../gameplay/design.md#grid) defines the reaches used by required routes. Gift rooms
permanently unlock Dash, Double jump and Speedy. The player can select one or play with none.
Ordinary required routes need no skill.

Reference: [Chibi](../../gameplay/design.md#chibi).
