# Progression

Stages unlock in route order and stay replayable. A fresh entry generates a layout. Try again
starts another attempt on that layout. Statistics group Last time, Best time and Attempts
separately from Stage, Zone and Run totals. Confirmed Restart resets progress and totals and
preserves best times and achievements.

Reference: [map](../../gameplay/design.md#map), [achievements](../../gameplay/design.md#achievements), [save data](../../src/README.md#save-data).
